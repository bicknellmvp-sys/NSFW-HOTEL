**Color me NSFW** is a digital coloring application focused on high-complexity, editorial, and provocative line art for adults. Featuring strong male portraits, brutalist design elements, and subtle homoerotic motifs, it is crafted with a bold aesthetic for fans of raw, masculine digital art.

---

## ✨ Key Features

- 🖋️ **Intricate Line Art**: High-resolution line art curated specifically for advanced adult colorists.
- 🏛️ **Focus on the Male Form**: Detailed character portraits, anatomical studies, and editorial artwork celebrating masculine beauty.
- 👁️ **NSFW Blur Reveal**: Interactive UI components (`.nsfw-blur` / `.nsfw-reveal`) to dynamically preview artwork.
- 🖤 **Dark Editorial Aesthetic**: Custom-styled Tailwind CSS dark mode configuration.

## 🛠️ Tech Stack & Setup
